# QtChatClient 开发计划

本文档用于说明 QtChatClient 当前阶段目标、已完成内容、待办事项与后续里程碑。

## 1. 当前阶段定位

当前项目处于客户端基础框架搭建阶段，重点是：

1. 建立基础数据模型。
2. 完成主窗口骨架布局。
3. 打通基础构建与运行流程。
4. 为后续会话、好友、消息等业务功能预留扩展入口。

## 2. 当前已完成内容

截至当前版本，已确认完成的内容包括：

1. UserInfo、ChatSessionInfo、MessageType、Message 等基础数据结构定义。
2. Message 工厂方法与基础消息字段填充逻辑。
3. Utils 与 Log 公共能力封装。
4. MainWidget 单例入口与主窗口基础创建。
5. 左中右三栏主界面骨架布局。
6. 左侧导航标签按钮与图标切换逻辑。
7. 项目基础 CMake 构建与 Qt 资源集成。

## 3. 当前待完成内容

结合现有代码状态，当前待完成项主要包括：

1. 中间列表区 UI 实现。
2. 右侧内容区 UI 实现。
3. 会话列表数据组织与展示。
4. 好友列表与好友申请列表展示。
5. 聊天消息区域与输入区域实现。
6. 附件消息真实 ID 与附件流转逻辑。
7. 网络通信与服务端联调能力。
8. 自动化测试补充。

## 4. 建议的开发里程碑

建议将后续开发拆分为以下里程碑：

### M1 界面骨架完善

目标：完成中间区与右侧区的界面占位升级，形成完整可交互页面结构。

建议内容：

1. 完成会话列表区布局。
2. 完成右侧聊天详情区布局。
3. 根据标签切换刷新中间区域内容。

### M2 本地业务流程打通

目标：在无服务端联调前，先打通本地假数据驱动的会话和消息展示。

建议内容：

1. 准备假数据。
2. 驱动会话列表展示。
3. 驱动聊天消息区域展示。

### M3 网络与协议接入

目标：接入服务端接口，实现真实数据通信。

建议内容：

1. 设计并实现网络层。
2. 对接登录、拉取会话、发送消息等核心接口。
3. 完成错误处理与状态同步。

### M4 测试与稳定性完善

目标：提升项目可维护性与稳定性。

建议内容：

1. 补充单元测试。
2. 补充界面行为测试。
3. 建立更清晰的问题排查与回归验证流程。

## 5. 当前文档维护要求

当以下信息变化时，应同步更新本文件：

1. 阶段目标变化。
2. 已完成功能变化。
3. 待办优先级变化。
4. 里程碑计划变化。

## 6. 当前状态标记

本文件中的“当前阶段定位”“当前已完成内容”“当前待完成内容”是基于现有代码的阶段总结；“建议的开发里程碑”属于后续推进建议，可随着实际开发节奏调整。
