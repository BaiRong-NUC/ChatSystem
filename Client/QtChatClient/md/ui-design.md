# QtChatClient 界面设计说明

本文档用于说明 QtChatClient 的页面结构、交互流程、界面状态和设计约束。

## 1. 当前界面状态

当前客户端已经落地的是主窗口基础骨架，整体为三栏布局：

1. 左侧导航栏。
2. 中间列表区。
3. 右侧主内容区。

当前三栏界面已拆分为 MainWidget、LeftWidget、MidWidget、RightWidget 四个窗口类，其中 MainWidget 负责整体装配，其余三个类分别负责各自区域。

其中，当前已实现的主要是左侧导航栏和标签图标切换；中间区与右侧区仍处于占位阶段。

## 2. 当前页面结构

### 2.1 主窗口

| 区域       | 当前状态 | 说明                         |
| ---------- | -------- | ---------------------------- |
| 左侧导航栏 | 已实现   | 展示头像按钮和功能标签按钮   |
| 中间列表区 | 占位中   | 后续承载会话、好友、申请列表 |
| 右侧内容区 | 占位中   | 后续承载聊天详情或信息面板   |

对应类关系如下：

| 区域       | 对应类      | 说明                         |
| ---------- | ----------- | ---------------------------- |
| 主窗口     | MainWidget  | 负责三栏布局与子窗口装配     |
| 左侧导航栏 | LeftWidget  | 负责头像、导航按钮与状态切换 |
| 中间列表区 | MidWidget   | 负责列表区占位与后续扩展     |
| 右侧内容区 | RightWidget | 负责内容区占位与后续扩展     |

### 2.2 左侧导航栏

当前左侧导航栏包含以下元素：

| 元素         | 当前状态 | 说明                    |
| ------------ | -------- | ----------------------- |
| 头像按钮     | 已实现   | 当前显示默认头像        |
| 会话按钮     | 已实现   | 支持激活/未激活图标切换 |
| 好友按钮     | 已实现   | 支持激活/未激活图标切换 |
| 好友申请按钮 | 已实现   | 支持激活/未激活图标切换 |

## 3. 当前交互行为

当前已确认的交互逻辑包括：

1. 启动后默认激活“会话”标签。
2. 点击不同标签按钮时，会切换当前激活状态。
3. 重复点击当前已激活标签时，不重复刷新。
4. 标签切换当前仅影响按钮图标状态。
