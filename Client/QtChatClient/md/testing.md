# QtChatClient 测试说明

本文档描述 QtChatClient 当前的测试现状、手工验证项与后续测试补充方向。

## 1. 当前测试现状

截至目前，项目源码与顶层构建脚本中尚未定义独立的自动化测试目标，当前可以确认：

1. CMakeLists.txt 中未看到 enable_testing 或 add_test 配置。
2. 代码目录下当前没有单独的 tests 测试模块。
3. 项目目前仍以手工运行和界面验证为主。

因此，当前测试文档应以“手工验证 + 构建验证 + 后续测试规划”为主，而不是声称已有完整自动化测试。

## 2. 当前已完成的基础验证

当前已确认的基础验证包括：

1. 项目可以通过 CMake 正常配置和编译。
2. 可执行程序 QtChatClient 可以成功启动。
3. 最近一次本地运行 ./QtChatClient 返回码为 0。
4. 启动后主窗口能够展示。
5. 左侧导航标签可以响应点击并切换图标状态。

## 3. 建议的手工测试清单

在当前阶段，建议每次界面改动后至少检查以下项目：

1. 能否重新完成 cmake --build build。
2. 程序启动后是否正常显示窗口标题和窗口图标。
3. 左中右三栏布局是否完整显示，且没有明显错位。
4. 左侧导航默认是否激活“会话”标签。
5. 重复点击当前标签时是否保持稳定，不出现异常刷新或崩溃。
6. 在三个标签之间切换时，图标是否和激活状态保持一致。
7. 关闭窗口时程序是否正常退出。

## 4. 当前测试缺口

目前仍缺少以下测试覆盖：

1. Message::CreateMessage 的字段填充单元测试。
2. Utils 文件读写与时间格式化的单元测试。
3. Log 过滤级别行为测试。
4. MainWidget 初始化与标签切换行为测试。
5. 未来聊天会话列表、消息收发、附件处理相关测试。

## 5. 后续测试建议

当项目继续推进时，建议按以下顺序补齐测试：

1. 先为数据模型和工具函数补充单元测试。
2. 再为主窗口状态切换补充界面行为测试。
3. 最后再补充消息流、网络交互和端到端测试。

## 6. 文档维护原则

后续只要发生以下变化，就应同步更新本文件：

1. 新增自动化测试目标。
2. 新增测试目录或测试框架。
3. 手工验证步骤发生变化。
4. 已确认的运行结果或测试结论发生变化。
